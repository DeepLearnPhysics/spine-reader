# include

## Overview

The public header tree of the `spine_reader` library. CMake exports this directory as the
build-interface include path (`target_include_directories` in `CMakeLists.txt`) and installs
`include/spine` to `${CMAKE_INSTALL_INCLUDEDIR}`. Only headers are installed: the install rule
excludes the `EGM.md` files (`PATTERN "EGM.md" EXCLUDE`). Consumers write
`#include <spine/reader.hpp>`.
Everything lives under the `spine` namespace directory.

## Subdirectories & Boundaries

- spine: [./spine/EGM.md](./spine/EGM.md): the public API. `Reader`, `ReaderOptions`, `Event`,
  `Match`, `SchemaReport`, `Error`, the reflection descriptors, and the `Object<N>` base. It
  contains:
  - [./spine/model/EGM.md](./spine/model/EGM.md): SPINE 1.4.0 classes and enums generated by
    `tools/gen/generate.py` (do not hand-edit).
  - [./spine/detail/EGM.md](./spine/detail/EGM.md): internal `ColumnBuffer` and
    `assign<&Class::member>` row-copy templates.
