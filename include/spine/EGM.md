# spine

## Overview

The public C++ API of spine-reader, a reader for SPINE HDF5 output files (V1 and V2 layouts).
A `Reader` opens one or more files and presents them as one sequence of immutable `Event`s.
Each event gives typed access to the SPINE objects (particles, interactions, run info, ...) and
resolves the relations between them. A `SchemaReport` records, for each file, how its products
lined up with the generated model. The model classes come from `./model`, and the static
reflection tables they use come from `descriptor.hpp`. All of these headers are implemented in
`src/`.

## Interface

- `reader.hpp`
  - `struct ReaderOptions { std::vector<std::string> products; bool allow_incomplete = false;
    bool strict = false; }`
  - `class Reader`: constructed from a path or a list of paths (`Reader(path, options)`), and
    movable. Methods: `num_events()`, `event(index)`, `num_files()`,
    `schema_report(file = 0)`, and `find(run, subrun, event) -> std::optional<std::uint64_t>`.
- `event.hpp`
  - `template <class T> struct Match { const T* object; float overlap; }`
  - `class Event`: `index()`, `file_index()`, `entry()`, `has(product)`,
    `reco_particles()`, `reco_interactions()`, `truth_particles()`, `truth_interactions()`,
    `run_info()`, `meta()`, `objects<T>(product)`, `particles_of(interaction)`,
    `interaction_of(particle)`, and `matches(...)` for each reco/truth particle/interaction
    pairing.
- `schema_report.hpp`
  - `struct ProductReport`: `product`, `class_name`, `missing`, `mismatched`, `extra`,
    `enum_notes`, and `complete()`.
  - `struct SchemaReport`: `path`, `spine_version`, `format_version`, `layout`
    (`"V1"`, `"V2Root"` or `"V2Products"`), `model_version`, `products`, `skipped`, and
    `summary()`.
- `descriptor.hpp`
  - `enum class ScalarType`, `constexpr scalar_size(ScalarType)`, and `to_string(ScalarType)`
  - `struct EnumMember` and `struct EnumDescriptor` (with `name_of(value)`)
  - `enum FieldFlag` (`kDerived`, `kPosition`, `kVector`, `kIndex`, `kCategorical`, `kPdg`,
    `kPdgMinusOneValid`, `kPointwise`, `kLiteSkip`)
  - `struct FieldDescriptor` (`name`, `type`, `count`, `variable`, `flags`, `units`,
    `enumeration`, `reference`, `reference_space`, `doc`, `assign`; `derived()`)
  - `struct ClassDescriptor` (`name`, `fields`, `num_fields`, `schema_version`; `find(name)`,
    `index_of(field)`)
- `object.hpp`: `template <std::size_t N> class Object`, the base of every generated class.
  It has `kNumFields` and the protected `has_field(index)`. `detail::ObjectAccess::set_present`
  is used by the binder.
- `error.hpp`: `class Error : public std::runtime_error`.
- `model.hpp` (generated by `tools/gen/generate.py`, do not edit): umbrella include of every
  model header, `SPINE_READER_MODEL_SPINE_VERSION` (`"1.4.0"`), and the X-macro
  `SPINE_READER_FOR_EACH_CLASS(X)`.
- Subdirectories:
  - [model](./model/EGM.md): generated SPINE classes and enums
  - [detail](./detail/EGM.md): internal column buffer and member-assignment templates

## Invariants

- Failures are reported as `spine::Error` (`error.hpp`). Errors raised while opening or
  reading a file name the file, and the product when one is involved. HDF5 failures also give
  the innermost HDF5 error. Two errors name no file: an out-of-range `event(i)` and a class
  mismatch in `objects<T>`, which names only the product. `schema_report(i)` with an
  out-of-range `i` throws `std::out_of_range`. The library never prints.
- `Reader::event(index)` counts across files in the order given and throws if `index` is out
  of range.
- By default (`allow_incomplete = false`), files with `/info@complete == false` are rejected.
  With `strict = true`, a product that lacks model fields throws instead of being reported.
- An empty `ReaderOptions::products` means every product whose class the model knows.
- `Reader::find`: the first call reads `run_info` for every file. When a (run, subrun, event)
  triple repeats, the first event wins. If any file has no `run_info` product, `find` throws
  `spine::Error` (`src/reader.cpp`).
- `Event` is cheap to copy (it shares a `std::shared_ptr<const detail::EventData>`), immutable,
  and safe to share across threads.
- `Event::objects<T>(product)` returns an empty vector when the product is absent and throws
  `spine::Error` when the product holds a class other than `T`. `run_info()` and `meta()`
  return nullptr when the product is absent.
- Relations are resolved by SPINE id within the event. Ids that point at nothing are skipped.
  `matches(...)` keeps SPINE's order, best overlap first. A match without an overlap entry
  gets `overlap` = NaN.
- A model field the file lacks keeps SPINE's default and `has()` returns false. Such fields are
  listed in `ProductReport::missing`, or in `mismatched` when the file's shape cannot be taken.
  `ProductReport::complete()` ignores `extra`.
- Enums are mapped by value, not by label. A file whose labels cross the model's does not bind
  (`descriptor.hpp`). Label differences are reported in `ProductReport::enum_notes`.
- `ClassDescriptor::fields` is ordered like the class's `Field` enum.
  `FieldDescriptor::count` is 1 for scalars, N for fixed arrays, and 0 for variable-length
  fields.

## Side Effects

- `Reader` opens and reads HDF5 files from disk. All HDF5 access is serialised behind one
  library-wide recursive mutex (`spine::core::hdf5_mutex()` in `src/core/mutex.cpp`). A
  `Reader` may be used from several threads, but reads do not run in parallel.
- `Reader::find` builds an in-memory (run, subrun, event) index (`Impl::run_index`) on its
  first call and reuses it afterwards.
