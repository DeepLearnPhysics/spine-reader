# model

## Overview

Generated field tables for the SPINE object model. **Every `.cpp` and `.hpp` file in this
directory is generated by `tools/gen/generate.py` from the committed SPINE schema
(the one `schema/spine-<version>.json`). Do not edit them by hand.** To
change them, regenerate with `python3 tools/gen/generate.py`. The generator deletes only
stale `.hpp` and `.cpp` files here, so this `EGM.md` is safe.

Each class source defines the `FieldDescriptor` table and the `ClassDescriptor` that
`descriptor()` returns for one public struct in `include/spine/model/<snake_class>.hpp`.
`src/bind/` uses these descriptors to bind file columns by name. `enums.cpp` defines the
`EnumDescriptor`s that the binder uses to compare enum labels.

## Interface

- Class sources (one per SPINE class). Each defines
  `const ClassDescriptor& <Class>::descriptor()`:
  - `crt_hit.cpp` (`CRTHit`), `flash.cpp` (`Flash`), `flash_hypothesis.cpp` (`FlashHypothesis`),
    `image_meta3d.cpp` (`ImageMeta3D`), `reco_interaction.cpp` (`RecoInteraction`),
    `reco_particle.cpp` (`RecoParticle`), `run_info.cpp` (`RunInfo`), `trigger.cpp` (`Trigger`),
    `truth_interaction.cpp` (`TruthInteraction`), `truth_particle.cpp` (`TruthParticle`).
  - Each table row is a `FieldDescriptor` (`include/spine/descriptor.hpp`) with these
    entries:
    - `name`, `type`, `count`, `variable`;
    - `flags` (`FieldFlag` bits such as `kIndex`, `kCategorical`, `kPosition`, `kVector`);
    - `units`, `enumeration`, `reference`, `reference_space`, `doc`;
    - the `&detail::assign<&Class::member>` setter.
  - Each `ClassDescriptor` is `{"<Class>", kFields, std::size(kFields), "<version>"}`. The last
    entry is the schema's SPINE version, which the Reader reports as `model_version`.
- `enums.cpp`
  - `EnumDescriptor`s: `kParticleShapeEnum`, `kParticlePIDEnum`, `kNuCurrentTypeEnum`,
    `kNuInteractionSchemeEnum`, and the per-generator interaction-type enums (LArSoft, Genie,
    GiBUU, NuWro, Neut).
  - `const EnumDescriptor* interaction_mode_enum(NuInteractionScheme)`: returns the LArSoft
    table for LARSOFT and the Genie table for GENIE, GIBUU, NUWRO and NEUT.
  - `const EnumDescriptor* interaction_type_enum(NuInteractionScheme)`: returns each scheme's
    own table.
  - Both return `nullptr` for any other scheme. They are declared in
    `include/spine/model/enums.hpp`.
- `field_check.hpp` (private, generated)
  - `detail::element_type<T>()`, `detail::MemberShape<M>` and `detail::field_matches<M>(d, name)`.
  - Macro `SPINE_MODEL_CHECK_FIELD(Class, name)`: a `static_assert` that a member's C++ type
    agrees with its descriptor row.

## Invariants

- Generated files must match what the generator produces from the committed schema. The
  ctest entry `spine_reader_generated_model` runs `tools/gen/generate.py --check` and fails
  on any difference or stale file.
- Each `kFields` table has one row per `Class::Field` enumerator, in order:
  `static_assert(std::size(kFields) == Class::kNumFields)`.
- Each member's element type, count and variable flag must agree with its row
  (`SPINE_MODEL_CHECK_FIELD`):
  - `std::array<E, N>` has count N and is fixed;
  - `std::vector<E>` and `std::string` are variable with count 0;
  - SPINE enums must have `std::int64_t` as underlying type.
- The enumeration and assign pointers are not checked at compile time (that is not a
  constant expression under `-fsanitize=undefined`). `tests/test_model.cpp` checks them at
  run time. The tables themselves are SPINE's: the golden test checks them against the current
  fixtures' columns, and `tests/test_contracts.cpp` the units and defaults the CAFMakers read.
- The descriptors are `constexpr` and `const` static data. They are read-only and safe to
  share across threads.

## Side Effects

- None. These files only define static tables and accessors. They do no I/O and take no
  locks.
